## 🚀 O que eu construo

Minha experiência transita por diferentes camadas do desenvolvimento de software:

```text
Frontend
   ↓
Interfaces e experiências web
   ↓
Mobile
   ↓
Aplicações multiplataforma
   ↓
Backend
   ↓
APIs, regras de negócio e integrações
   ↓
Database
   ↓
Persistência e modelagem de dados
   ↓
Infraestrutura
   ↓
Docker, ambientes e ferramentas de desenvolvimento
```

Gosto especialmente de trabalhar em projetos onde posso compreender o problema de ponta a ponta e participar das decisões que transformam uma ideia em software funcional.
